# Support, bugs, and security

Report ordinary bugs through [GitHub Issues](https://github.com/devsimon14-afk/structrakit-docs/issues).

Include:

- StructraKit, Python, and discord.py versions;
- operating system and architecture;
- minimal reproducible code;
- expected and actual result;
- complete traceback after removing sensitive data.

Never post bot tokens, user tokens, Authorization headers, private repository addresses, personal
data, or database contents. For a suspected security vulnerability, request a private reporting
channel from dev.simon before sharing exploit details.
